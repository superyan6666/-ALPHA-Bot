# 🧠 Knowledge Item (KI): Level 2 多周期共振与防爆流架构
**最后修订**: 2026-05-31
**适用组件**: `main.py`, `optimize_weights.py`, `feature_engine.py`

> [!NOTE]
> 本 KI 沉淀了我们在 Level 2 升级中做出的所有核心架构决策。未来涉及选股池、API 抓取或模型打分的修改，必须以本规范为准绳。

## 一、 数据防线与选股池漏斗 (Data & Filtering Funnel)

为了在**免费 API 额度**与**模型视野**之间取得完美平衡，系统采用“漏斗式”降维截断架构。

### 1. 宽基底座提取 (Universe Definition)
- **范围**：沪深300 + 中证500 + 中证1000 + 创业板指（约 1800 只流动性最充沛的个股）。
- **兜底方案**：若动态接口全部失效，系统自动回滚至静态“核心 50 股”白名单，拒绝无脑盲扫全市场。

### 2. 向量化快照与宽容预筛 (Vectorized Spot Prescreening)
- **机制**：通过一次极低成本的 API 调用获取全市场实时快照，并运用 `vectorized_prescreen` 进行基础打分。
- **长线适配偏好**：
  - 移除了短线偏好（不再奖励高量比和日内暴涨）。
  - 放宽了估值偏好（容忍 PE < 80, PB < 5）。
  - **红线惩罚**：仅对量比极度萎缩（< 0.4）、极小微盘、或触及涨跌停板（>9.5% 或 <-9.0%）的个股进行扣分。
- **Top 200 截断**：将初筛合格的标的**强制截断保留前 200 只**，仅对这 200 只发起耗时的历史 K 线下载请求。

### 3. API 熔断防封锁 (Circuit Breaker)
- 历史 K 线获取引入随机微延迟（0.3s~0.8s）及 `_GLOBAL_SEMAPHORE` 限制并发。
- **熔断机制**：单只股票重试 3 次，若连续 10 次获取不同股票均失败，触发 `RateLimit_CIRCUIT` 全局熔断，立即停止剩余下载任务并向上抛出异常。

## 二、 动态权重与多周期共振引擎 (Ensemble Engine)

彻底废弃了单维度或“拍脑袋权重”的打分方式，进化为数据驱动的交叉验证体系。

### 1. WFO 权重寻优 (Walk-Forward Optimization)
- **引擎**：`optimize_weights.py`
- **逻辑**：每周末自动读取过去 4 年的真实样本外（OOS）预测分，在网格中暴力搜索最佳的周期权重（Weights）组合，并将结果序列化入基因锁（`ensemble_weights.json`）。

### 2. 长短线解耦的双轨制 (Dual-Track Scoring)
在最终生成推送卡片时，系统强制切分“排序权”与“择时权”：
- **共振得分（决定排名）**：强行锁定 `T+1` 权重为 0。仅汇总 `T+5`, `T+10`, `T+20` 的得分计算加权总分，确保上榜榜单绝对由中长线趋势决定。
- **独立择时语义（决定买点）**：将提取出来的 `T+1` 原始分数转换为自然语言标签。
  - `T+1 > 80`: 🎯 早盘绝佳买点（短线超跌反弹动能强）
  - `T+1 < 35`: ⏳ 建议观望或逢低挂单（存在获利盘抛压）
  - `中段`: ⚖️ 常规建仓

## 三、 未来精修备忘录 (Next Steps / Tech Debt)

> [!WARNING]
> 以下技术债已被标记，须在下一个迭代（Level 2.1）中实施，否则会面临截面评分失效或单边熊市通杀风险。

1. **分数的量纲对齐 (Percentile Rank Standardization)**：
   - 当前各周期输出的绝对数值（如 80分 和 90分）未强制对齐正态分布。后续需要在截面上使用 `scipy.stats.rankdata` 转化为百分位 Rank，再进行加权。
2. **大盘通杀防范 (Beta Circuit Breaker)**：
   - 需实现基于大盘指数（如沪深300）的绝对形态过滤。若大盘日线跌破 60 日均线且 MACD 死叉，即使个股共振得分极高，也应强制拦截推送或发出空仓警告。
